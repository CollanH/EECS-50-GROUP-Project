Use scipy.signal.find_peaks as the baseline detector.

The detector:
- Receives sampled amplitudes and sampling frequency.
- Does not receive true BPM, pulse width, beat times, or the
  generator callable.
- Finds peaks and converts peak indices to times relative to the
  first sample, using peak_index / sampling_frequency.
- For plots requiring absolute times, use the sampler's returned
  timestamps, which include the sampling offset.
- Estimates BPM using:
    estimated_bpm = 60 / median(inter_peak_intervals_seconds)
- Returns estimated BPM, peak indices, peak count, and status.
- Reports insufficient_peaks with no numeric estimate when fewer
  than two usable peaks are detected.
- Distinguishes invalid input from a valid signal with insufficient
  detected peaks.
